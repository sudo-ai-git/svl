1 · Enthalpic N+1 Engine

Presets:
Equations used 
x[N+1] = x[N] + u[N] + f(x[N], u[N])
f(x,u) = −(k₁x + k₂x|x| + k₃ux)
reversal ⇔ sign(x[N+1] − x[N]) ≠ sign(u[N])
H = U + PV,  U[N] = U₀ + αU·x[N]
u[N] = u₀ + uAmp·sin(2π·uFreq·N + uPhase)

2 · Entropic Polarity Oscillator

Presets:
Equations used 
E_C = +E,  E_G = −E,  |E_C| = |E_G|
c[N+1] = c[N] + u₀ − γ(c[N] − g[N]) − κc[N] + η
g[N+1] = g[N] − u₀ + γ(c[N] − g[N]) + κc[N] − η
polarity = (c − g)/(c + g)
reversal ⇔ polarity changes sign through Ω

3 · Extraction, Sustainability, Synergy

Presets:
Equations used 
R[N+1] = R[N] + ρR[N](1 − R[N]/K) − C − E
E_val = (price − cost)·E        (V_captured − C_extraction)
S = regeneration − C            (R − C)
Y = V(A ⊕ B) − [V(A) + V(B)] = s·(V(A) + V(B))
reversal ⇔ extraction > 0 and R[N+1] < R[N]

4 · Knowledge Geometry & Observational Resolution

Equations used 
C_K = cos θ,  S_K = sin θ,  C_K² + S_K² = 1
K_parallel = k·cos θ,  K_perpendicular = k·sin θ
k² = K_parallel² + K_perpendicular²
δ ≈ B / D,  resolved ⇔ δ > ε
M[N+1] = M[N] ∪ {P[N+1]}

5 · Projection / Reflection Iteration

Equations used 
K[N+1] = F(P(K[N]), K[N])
Projection: rotate by φP, scale magnitude by p
Reflection: reflect across core axis (S → −S), rotate by φR, scale by r
coherence = cos Δθ between successive knowledge directions

6 · Realization vs Projection

Presets:
Equations used 
realized:    x[N+1] = x[N] + u + f_true(x[N]) + η[N]
projection:  x̂[N+1] = x[N] + u + f_model(x[N]) + bias
resolution difference: δ[N+1] = x[N+1] − x̂[N+1]
Prediction failure measures the model, not an incompleteness of the realized state.
