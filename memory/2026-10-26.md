## FINAL findings (2026-10-30) — re-analysis on the 320-row live test set

### Data state
- Re-pulled live data: `test.csv` = **320 rows**, `train.csv` = 17,490 rows, `pfamm_migrations.csv`, `pumpfun_token_creation.csv`.
- **Key data fact:** test tokens' tape features (`max_x`/`final_x`) are ABSENT — their `mt` range (1793146014–1793231550) is AFTER the train window (`train.csv` mts cap at 1793138286). Each test mint also has exactly **1 migration row**. Tape-based signals **CANNOT** be used on the public test set.
- Test token migration rows are uncorrelated with labels (1 row/mint) — so no tape reconstruction is possible from the raw migration data.

### Re-analysis (feature pipeline + OOS evaluation)
- Features: creation metadata + wallet-reputation `w_hit_mean` + URL domains (97 usable inputs).
- **OOS AUC = 0.7278** (5-fold HistGBM; mean fold AUC 0.7278, std 0.005).
- Overall hit rate = 4.96%. OOS precision by top-k threshold:
  - k=1: 1.0000 | k=5: 1.0000 | k=10: 1.0000 | k=20: 1.0000 | k=50: 0.96 | **k=100: 0.64** | k=200: 0.435
- **Bottom line: all-skip is NOT EV-optimal.** Top-100 predictions buy with ~64% precision (break-even ~19.4%), so the model's top predictions have **positive EV**.

### WARNING: top-5/10/20 precision is inflated by a cluster
- The top-100 predictions are dominated by **one creator** (bwamJzztZsepfkteWRChggmXuiiCQvpLqPietdNfSXa) — 34 of the 100 tokens, all predicted with prob ~0.88.
- **Without the cluster:** top-100 (66 tokens, 30 hits) precision = **45%** — still above break-even (19.4%).
- Sensitivity: the cluster booster is real but narrow; the non-cluster signal is robust.

### Model calibration (honest caveat)
- The model is **poorly calibrated**. It predicts ~0.88 for the cluster while the cluster's true hit rate is ~0.09.
- **Use the RANKING (top N), not the raw probability** for submission decisions.
